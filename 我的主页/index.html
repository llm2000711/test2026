MODULE 01

为什么律师需要一个个人主页？

🔍

客户在搜索你

超过80%的企业客户在委托前会搜索律师信息。如果没有个人主页，搜索结果中出现的可能是律所名录、裁判文书甚至负面信息。

📱

名片不够用了

纸质名片只能传递姓名和电话。个人主页可以展示专业领域、代表案例、文章观点，让客户在见面前就建立信任。

⚖️

同行也在看

合作律师、企业法务、学术机构都会通过主页了解你的专业方向，主页是建立同行 referral 网络的重要入口。

传统方式的局限

  • 律所官网介绍更新慢、内容固定
  • 朋友圈营销碎片化、难以系统展示
  • 短视频平台不适合深度专业展示
  • 没有属于自己的"数字资产"

个人主页的优势

  • 完全自主可控，随时更新
  • 系统化展示专业能力和服务
  • 一个链接即可分享，适配所有场景
  • 长期积累形成内容资产和搜索权重
在AI时代，律师的核心竞争力不只是专业能力，更是让潜在客户"看见"你专业能力的能力。

MODULE 04

用AI提炼你的"一句话定位"

主页的第一屏，决定了客户是否会继续往下看。一句话定位是整个主页的灵魂。

定位公式

我是谁 + 服务谁 + 解决什么问题 + 我的独特优势

AI PROMPT · 提示词模板
我是一名执业【X】年的律师，主要业务方向是【业务领域】，服务的主要客户类型是【目标客户】。请帮我写3个版本的个人主页一句话定位，要求： 1. 客户3秒内能看懂 2. 突出我的细分专业优势 3. 避免使用"专业""资深""精通"等空泛词汇 4. 每个版本控制在30字以内

AI输出的三个版本

  • 版本A：专注企业合同风险审查与商事争议解决，为成长型企业提供从防范到诉讼的全链条法律服务。
  • 版本B：帮助科技企业处理股权纠纷与合规风险，用商业思维解决法律问题。
  • 版本C：15年商事争议解决经验，擅长将复杂法律问题转化为可执行的解决方案。
律师需做的判断：AI给出的版本需要你根据自己的实际情况选择和修改。定位不是AI的创意写作，而是你对自己执业方向的清醒认知。AI只是帮你把模糊的想法变成精确的文字。
MODULE 05

主页六屏架构：只做客户最关心的

不要把主页做成简历。要做成一个"客户决策页面"——每一屏都在回答客户的一个问题。

屏模块客户的问题内容要点
1首页 Hero你是谁？能帮我解决什么？姓名、定位、主按钮、头像
2专业领域你具体做哪类业务？用客户问题命名服务，3-6个模块
3代表案例你做成过什么？问题→动作→结果→价值，脱敏呈现
4文章观点你的专业深度如何？新规解读、热点分析、办案复盘
5资质背书你能被信任吗？执业经历、教育背景、荣誉、社会职务
6联系入口怎么找到你？电话、邮箱、二维码、预约按钮
不做简历：不要按时间线罗列工作经历，客户不关心你的履历顺序。
做决策页：每一屏都在帮客户回答"要不要联系你"这个问题。
减法原则：能删的内容就删。一屏只传递一个核心信息。
MODULE 06

提示词工程：让AI写出律师级文案

同样的AI工具，不同的提示词，结果天差地别。掌握提示词结构，是AI时代的核心技能。

提示词四要素（CRSP框架）

  • Context（背景）：告诉AI你的身份、执业年限、业务方向
  • Role（角色）：让AI扮演"律师个人品牌顾问"
  • Specific（具体）：明确要什么内容、多少字、什么风格
  • Pattern（格式）：指定输出格式——列表、表格、段落
关键原则：你给AI的约束越具体，输出质量越高。模糊的提示词 = 模糊的结果。
AI PROMPT · 完整示例
【背景】我是一名执业12年的商事律师，专注企业合同纠纷和股权争议，服务对象主要是中小企业。 【角色】请扮演律师个人品牌顾问。 【任务】为我的个人主页"业务领域"模块撰写6个服务项目的标题和简介。 【要求】 1. 标题用"客户问题"而非"法律术语"命名 2. 每个简介2-3句话，说明能解决什么问题 3. 避免绝对化表述和承诺结果 4. 风格专业、克制、可信 【格式】标题 + 简介，逐条列出。

✕ 糟糕的提示词

  • "帮我写律师主页内容"
  • 没有背景信息
  • 没有格式要求
  • 没有风格约束
  • → 输出泛泛而谈，无法直接使用

✓ 优秀的提示词

  • 有身份、年限、方向
  • 有角色设定
  • 有具体数量和字数
  • 有风格和合规约束
  • → 输出精准、可用、合规
MODULE 07

首页第一屏：AI生成与人工校准

第一屏是客户看到的第一眼。用AI生成初稿，再用律师的专业判断校准。

第一屏的4个要素

  • ① 姓名 + 律师身份：让客户立刻知道你是谁
  • ② 一句话定位：你帮谁解决什么问题
  • ③ 行动按钮："预约咨询""联系我"
  • ④ 职业头像：建立第一印象和信任
第一屏法则：客户3秒内必须看到——你是谁、你做什么、怎么联系你。看不到这三个信息，客户就会离开。
AI PROMPT · 生成首页代码
请用HTML和CSS生成一个律师个人主页的首页第一屏（Hero section），要求： 1. 深色法律蓝背景（#0A1628），金色强调色（#C9A84C） 2. 左侧：大标题"张明律师"+ 副标题"专注企业商事争议解决" + 金色按钮"预约咨询" 3. 右侧：圆形头像占位符 4. 响应式设计，手机端单列排列 5. 风格专业、克制、有质感 请直接输出完整的HTML和CSS代码。
人工校准清单：AI生成代码后，律师需检查——① 姓名和定位是否准确 ② 配色是否符合品牌调性 ③ 按钮链接是否指向正确的联系方式 ④ 头像是否替换为真实职业照 ⑤ 手机端显示是否正常。

客户看不懂，也不知道你能帮他做什么

✓ 推荐：客户问题式

  • 企业合同风险审查与争议解决
  • 股权架构设计与股东纠纷处理

客户一看就知道——"这正是我遇到的问题"

MODULE 09

案例展示：AI辅助脱敏与结构化

案例不是炫耀结果，而是证明你解决问题的能力。用AI帮你把案例结构化呈现，同时确保脱敏合规。

案例四段式结构

  • 案情：客户遇到了什么问题？
  • 动作：你做了哪些关键工作？
  • 结果：案件取得了什么结果？
  • 价值：为客户避免了/挽回了什么？
展示原则：用"问题→方案→结果"的逻辑，让客户看到你的分析能力和解决路径，而不是仅仅看一个胜诉数字。
AI PROMPT · 案例结构化与脱敏
以下是我的一个案件信息： 【原始信息：代理某科技公司应对供应商合同纠纷，涉及金额300万，最终通过谈判达成和解，客户仅需支付120万。】 请帮我： 1. 按照"案情→动作→结果→价值"四段式结构重写 2. 对公司名称、金额、具体细节进行脱敏处理 3. 确保不包含任何可能识别客户身份的信息 4. 控制在150字以内 5. 不使用"胜诉""大获全胜"等绝对化表述
合规红线：案例展示必须脱敏——隐去当事人姓名、公司全称、案号、身份证号、具体地址。判决书截图必须遮挡敏感字段。不得使用"保证胜诉""百分百追回""全国第一"等违规表述。AI可以帮助脱敏，但最终合规判断必须由律师亲自完成。
MODULE 10

文章观点：AI辅助专业内容生产

文章是长期获取客户信任的入口。AI可以帮助你高效产出专业内容，但核心观点必须是你自己的。

文章的标准结构

问题场景

客户遇到的典型问题

法律分析

核心法律关系与风险点

解决建议

可执行的实操建议

律师观点

你的专业判断

标题示例：新《公司法》下，股东出资期限加速到期的3个实务问题

AI辅助写作流程

  • Step 1：你提供选题方向和核心观点
  • Step 2：AI生成文章框架和初稿
  • Step 3：你审核法律准确性、补充实务经验
  • Step 4：AI润色语言、优化结构
  • Step 5：你做最终合规审查后发布
关键提醒：AI可能引用过时的法条或编造案例。所有法律依据必须由律师逐一核实原文。AI生成的内容是草稿，不是终稿。
文章的价值不在于"写了多少"，而在于"帮客户解决了什么认知"。一篇精准的实务文章，胜过十篇泛泛的理论综述。

AI PROMPT · 生成完整主页

AI生成代码后的操作步骤

MODULE 12

GitHub Pages发布：从本地到公开网址

GitHub Pages提供免费的静态网站托管。无需服务器、无需域名费用，一个公开链接即可分享。

Step 1
注册GitHub账号
访问 github.com 注册免费账号。建议用户名与你的姓名/品牌相关，因为网址中会包含用户名。
Step 2
新建仓库（Repository）
点击 New Repository，名称建议为 lawyer-homepage 或你的名字拼音。选择 Public（公开），勾选 Add README。
Step 3
上传 index.html
点击 Add file → Upload files，将AI生成的 index.html 拖入上传。如有图片，先创建 images 文件夹再上传。
Step 4
开启 GitHub Pages
进入仓库 Settings → Pages → Source 选择 main 分支和 root 目录 → Save。
Step 5
获取公开链接
等待1-2分钟后，Pages页面会显示你的网址：https://用户名.github.io/仓库名/ ——这就是你的个人主页地址。
免费优势：GitHub Pages 完全免费，无流量限制，支持自定义域名，全球CDN加速，HTTPS自动启用。
常见问题：如果显示404，检查文件名是否为 index.html、Pages分支是否选对main/root、文件是否已成功上传。
MODULE 13

PDF导出与离线展示

个人主页可以一键导出为PDF，用于邮件附件、线下递交、打印材料等场景。

浏览器导出PDF的步骤

  • ① 在浏览器中打开你的个人主页网址
  • ② 按 Ctrl+P（Mac: Cmd+P）打开打印对话框
  • ③ 目标打印机选择"保存为PDF"
  • ④ 布局选择"纵向"（适合手机阅读）
  • ⑤ 边距选择"无"或"默认"
  • ⑥ 勾选"背景图形"保留配色
  • ⑦ 点击保存，生成PDF文件

PDF的使用场景

  • 邮件附件：客户邮件咨询时，附上PDF版主页介绍
  • 线下递交：面谈时打印一份作为个人简介材料
  • 微信分享：生成PDF后可直接在微信中发送
  • 投标材料：作为法律服务投标的律师简介附件
  • 离线备份：即使网站临时无法访问，PDF仍可用
专业提示：建议同时在主页中加入"下载PDF简介"按钮，方便客户自行保存。AI可以帮你生成这个按钮的代码。
一个链接 + 一个PDF = 覆盖线上分享和线下递交的全部场景。
MODULE 14

合规红线：律师营销的法律边界

AI可以帮你写文案，但合规判断必须由律师亲自完成。以下是律师个人主页的绝对红线。

✕ 绝对不能写

  • 保证胜诉、百分百追回、万无一失
  • 全国第一、最专业、唯一、顶级
  • 未授权使用的客户名称和评价
  • 未脱敏的判决书、合同、聊天记录
  • 暗示与司法机关有特殊关系
  • 贬低其他律师或律所
  • 不实宣传执业年限、学历、荣誉
  • 未经审批的收费承诺和风险代理宣传

✓ 可以且应当写

  • 专注的某类业务领域和方向
  • 代表性项目经验（已脱敏）
  • 公开发表的文章和公开活动
  • 已脱敏、客观描述的案例过程
  • 真实的执业经历、教育背景
  • 真实的社会职务和学术成果
  • 客观的专业资质和认证
  • 联系方式和服务流程说明
法律依据：《律师法》《律师执业行为规范》《律师执业管理办法》以及各地律协关于律师宣传的相关规定，均对律师营销行为有明确约束。违反者可能面临警告、罚款、暂停执业甚至吊销执照的处分。AI不知道这些规则，你必须自己把关。
AI使用中的合规提醒：AI可能生成"保证为您争取最大利益""胜诉率极高"等违规表述。每次使用AI生成的内容，都必须逐句审查是否触碰红线，修改后再发布。
